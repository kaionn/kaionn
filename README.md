## 💼 Career

フルスタックエンジニアとして働いています。業務では Rails / Go でバックエンドを書き、React / Next.js のフロントエンドから、Terraform と GitHub Actions による AWS の構築・運用まで担当しています。

個人開発では、ブラウザで遊べるゲームを公開し、毎朝自動で更新される技術ニュースと基礎解説も回しています。
